Steam gauges and glass displays (or part of one) can sit side by side in a layout.
Each row is a physical screen: a display app shows it when started with --screen <id> (or with the screen chosen in its Settings). All aircraft: glass cockpits show the chosen glass display (Automatic: the cockpit's own displays in order, PFD first); other aircraft show the layout. An aircraft column overrides that while the aircraft is loaded. The loaded aircraft always has a column.
CockpitCast puts a small add-on, the hook, into MSFS's Community folder. It tells CockpitCast where each glass display is. It holds a copy of one sim file, so reinstall it after every MSFS update. Reinstalling rebuilds it from your sim's current files.

Community folder

The folder MSFS loads add-ons from. With MSFS Addons Linker: the Community folder set in its Options (where it puts the links), not your add-ons library: MSFS does not read the library. CockpitCast remembers the folder you install into.
